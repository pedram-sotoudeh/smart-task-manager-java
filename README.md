# Smart Task Manager (Java Console Application)

A structured and object-oriented task management system developed in Java. This project demonstrates core software engineering concepts such as clean architecture, modular design, and data persistence.

---

## 🚀 Key Highlights
- Built using **Object-Oriented Programming (OOP) principles**
- Implements **file-based persistence (save/load tasks)**
- Includes **task analytics (statistics dashboard)**
- Designed with **modular architecture (separation of concerns)**
- Console-based system focusing on logic and functionality

---

## ✨ Features
- Add new tasks with title, description, priority, and deadline  
- Mark tasks as completed  
- Delete tasks  
- Search tasks by title  
- Show overdue tasks  
- Sort tasks by deadline  
- Sort tasks by priority  
- Filter completed and pending tasks  
- Persistent storage (Save & Load from file)  
- Exit with save or clear all data  
- View task statistics (total, completed, pending, overdue)

---

## 🧠 Technologies Used
- Java (OOP principles)
- File Handling (Read/Write)
- Collections Framework (ArrayList)
- Date API (LocalDate)

---

## 🏗️ Project Structure
- `Task.java` → Model class representing a task  
- `TaskManager.java` → Business logic and task operations  
- `Main.java` → Console-based user interface
