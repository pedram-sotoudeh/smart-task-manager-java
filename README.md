# Smart Task Manager (Java Console App)

A professional console-based task management system built in Java.

## Features

- Add new tasks with title, description, priority, and deadline
- Mark tasks as completed
- Delete tasks
- Search tasks by title
- Show overdue tasks
- Sort tasks by deadline
- Sort tasks by priority
- Filter completed and pending tasks
- Persistent storage (Save & Load from file)
- Exit with save or clear all data

## Technologies

- Java (OOP principles)
- File Handling (Read/Write)
- Collections (ArrayList)
- Date API (LocalDate)
